르엘 UI · 내 글꼴 넣는 법

1. 받은 글꼴 파일(.ttf 또는 .otf)을 이 폴더(LeelUI\MyFonts)에 넣어요.
2. 같은 폴더의 list.lua 를 메모장으로 열어요.
3. LeelUI_MyFonts = { } 안에 이렇게 한 줄을 적어요.
     { "파일이름.ttf", "목록에 보일 이름" },
   예) { "Cafe24DongdongRegular.ttf", "카페24 동동" },
4. 저장하고 게임을 껐다 켜요.
5. 허브 > 화면 > 르엘 글씨체 에서 골라요.

주의
- 파일 이름은 영어/숫자로 된 이름이 안전해요.
- 한글이 들어 있는 글꼴이어야 한글이 안 깨져요.
- 따옴표나 쉼표가 빠지면 르엘 UI 가 안 켜질 수 있어요. 그럴 땐 그 줄을 지우고 다시 켜 주세요.
