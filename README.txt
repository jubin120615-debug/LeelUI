르엘 UI (Leel UI) v1.3.3
WoW Forever (인터페이스 16001)용 연분홍 토끼 통합 UI

[들어 있는 애드온]
- 르엘 UI      : HUD(내 캐릭터 · 대상), 적 이름표, 파티 프레임, 시전바, 르엘 허브, 르엘 글씨체
- Leel Map     : 세계 지도 꾸미기, 걸을 때 흐려짐, 좌표, 지역 레벨
- Leel Mark    : 파티 징 자동 찍기 바와 단축키
- Leel Spot    : 퀘스트 물건 위 토끼 이름표 + 진행도 (Questie 있으면 더 정확)
- 르엘 길잡이  : 레벨링 길잡이

[설치]
압축을 풀면 나오는 폴더 5개를 통째로 아래 폴더에 넣어요.
  World of Warcraft\_forever_\Interface\AddOns
CurseForge 앱으로 설치하면 이 과정은 필요 없어요.

[여는 방법]
- 미니맵 토끼: 좌클릭 = 르엘 허브, 우클릭 = 이동 모드
- 채팅창 /르엘 (허브), /leel (르엘 UI 상세 설정)

[르엘 허브]
- 위쪽 알약으로 분류(화면 / 지도·길 / 파티·전투)를 고르고,
  왼쪽 스위치로 애드온 켜기·끄기, 오른쪽에서 자주 쓰는 설정.

[르엘 글씨체]
- 허브 > 화면 > 르엘 글씨체 에서 기본 글씨 / 이름·제목 / 채팅 / 숫자 / 크기를 고름.
- 내 글꼴 넣기: LeelUI\MyFonts 폴더의 "글꼴 넣는 법.txt" 참고.

[글꼴 라이선스]
- media\fonts 의 글꼴(고운돋움, 주아, 나눔고딕, 도현, 개구, 동글, 감자꽃)과
  Barlow Condensed 는 SIL Open Font License 1.1 (media\fonts\OFL-fonts.txt).
- MyFonts\Cafe24DongdongRegular.ttf 는 카페24 무료 글꼴 (저작권 카페24).
